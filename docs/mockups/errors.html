결과 없음 화면 아님 · 설정 오류

법제처 Open API 인증키(OC)가 등록되지 않았습니다

법제처 원문 조회에 필요한 서버 인증키가 없습니다. 연구 질의를 실행할 수 없습니다. 빈 카드 목록 대신 이 오류만 표시합니다.

  • OC 키 환경변수 없음 또는 만료
  • MCP(법제처 원문 조회)는 정상 — 키가 등록되면 즉시 검색 가능
비교: 「결과 없음」은 질의는 성공했으나 매칭 조문이 0건인 경우입니다. 본 화면은 질의를 보내기 전 구성 오류입니다.

GET /v1/health · mcp = down

결과 없음 화면 아님 · 원문 파이프라인 중단

법령 MCP 서버에 연결할 수 없습니다

법제처 원문 조회 경로가 내려가 있어 조문 카드를 만들 수 없습니다. 원문 URL 없는 추정 결과는 표시하지 않는 것이 원칙이므로, 검색 결과 영역 자체를 열지 않습니다.

MCP 중단 OC 정상
  • 원문 링크를 보증할 수 없으므로 카드 목록을 렌더하지 않음
  • 재시도 후에도 실패하면 지식관리 담당자에게 에스컬레이션

같은 「조문을 못 보여 줌」이 아닙니다. 왼쪽은 시스템 장애(미확정), 오른쪽은 원문상 부존재(확정).

LOOKUP_FAILURE · HTTP 503
